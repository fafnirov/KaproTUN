# Скриншоты для README

`README.md` и `README.ru.md` показывают по четыре кадра нового интерфейса:

| Кадр | Английский README | Русский README |
|---|---|---|
| Главный экран, подключено | `main-window.png` | `main-window-ru.png` |
| Список серверов | `servers.png` | `servers-ru.png` |
| Статистика | `statistics.png` | `statistics-ru.png` |
| Настройки | `settings.png` | `settings-ru.png` |

## Как их получить

Кадры не снимаются с экрана. Их рисует скрипт `make_screenshots.py`: он
запускает окно клиента без вывода на экран, во временной папке данных и с
выдуманными серверами, и сохраняет кадры в двойном разрешении.

Из корня репозитория:

```
python docs/screenshots/make_screenshots.py docs/screenshots en
python docs/screenshots/make_screenshots.py docs/screenshots ru
```

Скрипт ничего не подключает, не трогает настоящую папку данных, правила
брандмауэра и процессы. После смены интерфейса достаточно запустить его
заново и закоммитить изменившиеся файлы.

## Что на кадрах

Только выдуманные данные: серверы на `*.example.net`, внешний адрес
`203.0.113.21` (диапазон для документации), придуманный трафик. Настоящих
адресов серверов, ссылок подписок и путей с именем пользователя на кадрах
нет и быть не должно. Если меняешь скрипт, проверь это перед коммитом: кадры
публикуются вместе с кодом.
